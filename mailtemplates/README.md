# YowlChat mailtemplates

Deze map bevat copy-paste HTML templates voor YowlChat e-mails.

## Bestanden

- `confirm-signup.html` - bevestigingsmail voor nieuwe accounts
- `reset-password.html` - password reset mail met een code

## Placeholders

Gebruik deze variabelen in je mailgenerator:

- `{{appName}}`
- `{{displayName}}`
- `{{code}}`
- `{{expiresMinutes}}`
- `{{supportEmail}}`

## Toon

De templates zijn bedoeld voor een luxe YowlChat look:

- donker violet/paarse achtergrond
- glow-randen en zachte schaduwen
- sierlijke zijkanten met ornamenten
- code centraal en duidelijk zichtbaar
- korte veiligheidstips onderaan
